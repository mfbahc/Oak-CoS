# Synthetic User Example

This folder contains synthetic data only. It is for demos, tests, and first-run validation.

The fictional owner is Example Owner. The fictional organization is Example Company. The fictional domain is example.com.

Included examples:

- `reading-queue.md`: active review queue with current, waiting, and superseded items.
- `board-brief-refresh.md`: board briefing refresh shape with materials, questions, and vote guidance.
- `transcript-ingest.md`: transcript ingest output with decisions, commitments, and proposed durable updates.
