# Weekly Retro

Use local tasks, observations, calendar summaries, and project notes.

Return:

- wins
- misses
- commitments kept
- commitments missed
- recurring friction
- decisions to make
- one improvement for next week

Use the coaching lens only if the user asks or the retro clearly benefits from it. Do not drift into therapy.
