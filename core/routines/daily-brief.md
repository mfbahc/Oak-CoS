# Daily Brief Routine

Cadence: daily.

Default output: local note in `workspace/artifacts/`.

Use QMD/local search, today's tasks, recent observations, and relevant project notes. Do not contact anyone or update external systems without explicit approval.

If `workspace/context/current-actions.md` exists, use it as the compact source for live sign / check / flag / wait posture before reconstructing those items from tasks or old briefs.
