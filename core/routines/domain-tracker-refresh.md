# Domain Tracker Refresh Routine

Cadence: weekly.

Default output: local domain tracker update.

Review selected domain folders and propose updates. Do not cross domains without approval.

Start with a `Radar Summary`:

- material changes since last run
- stale active tracker or reading-queue copies
- current tracker files refreshed
- items needing human attention

Do not treat a source-ceiling bump as sufficient if new source material includes material deltas.
