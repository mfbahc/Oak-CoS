# Linear Connector Spec

Status: optional integration.

## Use For

Product, issue, project, and roadmap tracking.

## Permissions

May require workspace read access and optional write.

## Default Safety Mode

Read-only initially.

## Setup

Connect Linear and choose the relevant team or project.

## Disable

Revoke access and set `enabled = false` in `local/connectors.toml`.

## Never Without Approval

Do not create, update, assign, close, or comment on issues without explicit approval.
