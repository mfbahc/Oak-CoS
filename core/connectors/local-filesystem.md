# Local Filesystem Connector Spec

Status: optional integration.

## Use For

Reading selected local folders and writing local artifacts.

## Permissions

Requires folder access chosen by the user.

## Default Safety Mode

Selected folders only.

## Setup

Choose folders explicitly and record them in local config.

## Disable

Remove folders from local config and runtime access settings.

## Never Without Approval

Do not read broad folders, delete files, or move private data into public core files.
