# Briefing Docs

Use this folder for local review queues and board/project briefing materials.

Suggested structure:

```text
briefing-docs/
  index.md
  _to-read/       current unread review items
  read/           items the user has marked read
  superseded/     stale copies that were replaced by newer versions
```

Keep source artifacts in `workspace/artifacts/` or the relevant project/domain folder. The review queue can contain copies, exports, or links, but should record the source and refresh time in `index.md`.
