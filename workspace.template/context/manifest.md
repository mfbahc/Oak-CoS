# Context Manifest

This manifest describes local context areas. It does not authorize reading every file.

| Area | Path | Use |
| --- | --- | --- |
| Tasks | `workspace/tasks.md` | commitments and follow-ups |
| Observations | `workspace/observations/` | dated observations |
| Current actions | `workspace/context/current-actions.md` | live sign / check / flag / wait posture |
| Wiki | `workspace/wiki/` | stable local knowledge |
| Domains | `workspace/domains/` | domain context |
| Projects | `workspace/projects/` | project state |
| Artifacts | `workspace/artifacts/` | generated local outputs |
