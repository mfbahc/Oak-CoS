# Workspace Template

Copy this structure into `workspace/` through onboarding. The generated `workspace/` directory is ignored by git and holds private user state.

`briefing-docs/` is an optional review surface for board packs, trackers, PDFs, and other items the user needs to read. Keep source artifacts in their project/domain folders and use `briefing-docs/index.md` to track active, read, and superseded review copies.
